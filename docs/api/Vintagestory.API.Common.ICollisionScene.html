Stores and queries persistent colliders outside the normal terrain and entity broad phases. Registration changes and queries may run concurrently. Returned snapshots remain valid after their registration is updated or removed.

RegisterTransformedCollider(int, IReadOnlyList<Cuboidd>, ColliderTransform, bool, long, string?, bool, CollisionLayer, CollisionLayer, BlockPos?, IReadOnlyList<int>?)

Registers a collider whose boxes use collider-local coordinates. Updating its transform reuses that registered geometry. Colliders which carry entities can be used as moving platforms or floors. The owning entity's physics will ignore the collider when ownerEntityId is nonzero. An owner collider code can identify that local registration on the client and server through IEntityColliderProvider. keepsSupportedEntitiesDry prevents overlapping block liquid from affecting an entity while this collider supports it. Supplying a selection position makes the transformed boxes selectable as that block.

long RegisterTransformedCollider(int dimension, IReadOnlyList<Cuboidd> localCollisionBoxes, ColliderTransform transform, bool canCarryEntities = false, long ownerEntityId = 0, string? ownerColliderCode = null, bool keepsSupportedEntitiesDry = false, CollisionLayer collisionLayer = CollisionLayer.Solid, CollisionLayer collisionMask = (CollisionLayer)18446744073709551615, BlockPos? selectionPosition = null, IReadOnlyList<int>? selectionBoxIndices = null)

Sweep(TransformedCuboidd, double, double, double, int, List<CollisionHit>, CollisionQueryFilter?, bool)

Replaces the caller-owned list with one hit per collision box, ordered by fraction, collider ID, then box index. Sweeps translation against current snapshots without sweeping target motion or query rotation. Initial strict overlaps are included by default. Motion along or away from a touching surface is ignored. The query box must not be mutated until the call returns.

UpdateColliderTransform(long, int, ColliderTransform, double)

Updates the dimension and transform of a transformed collider without replacing its local geometry. elapsedSeconds is the time since the previous transform and is used to derive point velocity for carrying entities. It will pass zero when velocity is not known. Block-selection metadata is retained and must remain in the collider's dimension.
