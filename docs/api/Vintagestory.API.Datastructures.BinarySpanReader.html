Remarks

Equivalent to ReadBoolean().
This reads a whole byte to read one bool. If you have multiple bools you want to transport consider packing them into a large enough integer type.
A byte already has enough space to transport 8 bools by packing them into its bits.
This exists for convenience and parity with BinaryReader.
