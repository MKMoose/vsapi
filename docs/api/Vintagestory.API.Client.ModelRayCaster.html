Class ModelRayCaster

Namespace
Vintagestory.API.Client
Assembly
VintagestoryAPI.dll

Performs raycasting against a 3D mesh to determine UV coordinates from screen clicks. Also supports AABB-based hitbox detection for precise element selection. Useful for making clickable 3D UI elements.

Usage:

  1. Create raycaster: new ModelRayCaster(capi, () => yaw, () => pitch, () => scale, -1000)
  2. Load hitboxes: rayCaster.LoadHitboxes(hitboxes)
  3. On click: rayCaster.RayCastToHitbox(mouseX, mouseY, out ElementHitbox hitbox) Open in GitHub
