Description of one pool part (one chunk mesh in one LOD and one render pass)

The flags Hide, LodLevel, FrustumVisible and CullVisible are properties: while the part is in a pool they live in the pool slot arrays (PoolCullData) so culling reads them without touching this object After the part is removed from the pool the last values stay in this object

Note: this class implements no visibility rules All rules (the frustum test per mode, the LOD and view distance rule, the shadow pass threshold) live in FrustumCulling and the batched version lives in PoolCullData There is no separate per object version to keep in sync Open in GitHub
